STANLEY MUNYAO TECH — PORTFOLIO REDESIGN

This is the completed static website project. Open index.html through a local static server (for example: python -m http.server 5500).

The site includes a multi-page portfolio, five project case studies, five service disciplines, skills and about pages, journal templates, responsive contact form, SEO metadata, and the existing Sanity Studio foundation.

Before publishing:
1. Read SANITY_SETUP.md and configure the Sanity project ID for the public journal and private editorial Studio.
2. Configure a Formspree HTTPS endpoint in js/config.js if you want enquiries sent directly to a hosted inbox. The current fallback opens the visitor's email app and requires them to send the message.
3. Review README.md for the confirmed project claims and deployment notes.

The Studio is not deployed or linked to a Sanity account in this bundle. Keep its Sanity account access restricted to authorised editors. Do not add private tokens to frontend files.
