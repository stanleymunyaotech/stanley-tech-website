# Sanity Studio

This is the private editorial dashboard for the Stanley Munyao Tech website.

1. Read `../SANITY_SETUP.md`.
2. Install packages with `npm install`.
3. Set `SANITY_STUDIO_PROJECT_ID` and `SANITY_STUDIO_DATASET`.
4. Run `npm run dev`.

The Blog post schema includes content, publishing, SEO fields and an editor-only draft preview panel. Publishing and unpublishing use Sanity's built-in document workflow.
